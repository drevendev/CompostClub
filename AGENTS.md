# Compost Club

This is an independent React/TypeScript/Vite application. Work only in this project. Keep private briefing files, weights, portable runtimes and owner material out of public source and builds.

- Node 24 / npm 11, exact direct dependency pins and a project-owned lockfile.
- `npm run verify`, `npm run build`, `npm run package:single`, and real Chromium acceptance before release.
- Do not publish, push, create a public repository, register a domain or submit the competition entry without the owner's separate authorization.
- Never fabricate inference receipts or replace a failed model response with a canned result. Replay is restricted to exact public fixtures and visibly labelled everywhere, including exports.
- No cloud inference, product analytics, end-user accounts, paid services or hidden model downloads. Owner-authorized exception (22 October 2026): optional operator-only Sentry metadata tracing, disabled by default and excluding all idea/prompt/output content. It must be independently removable, require no card or paid upgrade, and never gate local/offline operation. The owner subsequently declined Render and Entire; do not set them up without a new explicit request. User ideas are untrusted text, never executable instructions or rendered HTML.
- Keep model failures and their original raw responses. A JSON/schema pass is not a semantic quality pass.
- Domain logic remains independent of React and inference runtimes. Save a sprout, consumed pair and spent slot atomically. Errors, cancellation and `no_blend` keep the slot.
- Preserve originals and source revisions. Deletion requires a cascade preview. Backups must be validated before replacement.
- Every delivery includes the verified standalone recorded HTML with its SHA-256 and source archive identity. Do not edit another project's standards or runtime.
