# Project audit — 21 October 2026

Reviewed source: `acb0d69fc4cd66bc839fbfb2de456c0061f9e28c` (main, merged recovery work). Node 24.19.0 / npm 11.17.0. This report and the revised roadmap are local documentation changes; application behavior was not modified.

## Assessment

Compost Club supports a coherent small creative workflow and has enough real technical evidence for a worthwhile article draft. It remains an experimental local application. A contest submission packet is incomplete: no deployed demo or recorded video, final English/template editing outstanding, human usefulness review pending. These are distinct from whether the code builds.

The strongest story is how a narrow, inspectable local Gemma task turns two unfinished ideas into a candidate concept, and how source quoting, model failures and human choice shaped its limits. Avoid claims of autonomous ideation, background generation, certified browser AI or measured time savings.

## Code and project

- React/TypeScript/Vite, exact direct dependency pins, a project lockfile, Node 24 / npm 11 requirements.
- Pure garden transitions cover slots, deterministic pairs, revision checks, immutable sprout parents, recompost and cascade deletion. They do not call React, WebGPU or Ollama.
- IndexedDB validates before writing and commits each garden atomically. Recent startup recovery preserves the unreadable original while installing a validated backup in one transaction.
- Inference adapters separate exact-fixture replay, opt-in Worker/WebGPU and loopback Ollama. User/model strings render as React text; model downloads are explicit.
- Repository CI, contribution guidance, issue forms, public-safe evaluation transcripts and a source allowlist exist. The exact-main [Repository checks run passed](https://github.com/drevendev/CompostClub/actions/runs/39557756439). Repository metadata showed public source and no Pages site at audit time.

## Article and Hacktoberfest readiness

**Ready to write:** purpose, visual loop, offline demo, inspectable architecture, real Gemma experiment history, negative results and an existing [draft](DEV_DRAFT.md). A strong angle: a quiet local idea garden, and why valid source quotes do not guarantee a good blend.

**Before contest submission:** obtain deployed demo or real video, complete the official English template, choose exact examples and honest limitations, check evidence identities, obtain human usefulness feedback where available and final owner authorization. Before a dependable product release, resolve data/trust defects and retest the candidate. A technical article can acknowledge an experimental build without pretending the whole backlog is closed.

The [Week 3 challenge](https://dev.to/challenges/hacktoberfest-week3-2026-10-19) uses Slow and Steady and weights writing quality most heavily. [Official rules](https://dev.to/page/hacktoberfest-week3-2026-10-19-contest-rules) require a new project created/completed in the entry period, open-source AI core, theme fit, open-innovation explanation, DEV template/tag, source, and deployed demo **or video**. Source dates are consistent with the window; repository creation alone does not independently prove when all work began. Best Use of Gemma is the evidenced partner route. Private-derived cases, domains and extra hosted partners are not prerequisites.

Deadline: **25 October 2026, 23:59 PDT = 26 October, 08:59 Asia/Nicosia**, after the Cyprus DST transition. The broader [Hacktoberfest 2026](https://hacktoberfest.com/) no longer uses PR counts for rewards. Filing these issues does not submit the project.
